# 扩充案例：从用户表达走到任务结果

主对照36例：24开发（X01—X24）、12冻结验证（H01—H12），六类各4开发/2验证。全部为作者编写的合成场景，不是真实用户调研或外部基准。开发与验证的原文、初态、金标在首次真实调用前固定。

原44个基础开发例按C/C2的ID去重，本轮加入24个定向开发例和12个验证例，再另增12个最终版验证例，共92例核心案例（68开发/24验证）；历史DD/A/Q实验单独存档。案例库规模不等于本轮真实运行分母。[目录定义](../../evaluation/case-catalog.json)。

原始目标、风速、窗帘、物理初态、缺失项和补答见[JSON定义](../../evaluation/product-expanded-cases.json)。真实结果与局限见[评测报告](expanded-evaluation.md)。
