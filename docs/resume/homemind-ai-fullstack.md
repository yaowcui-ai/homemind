# HomeMind｜智能家居 AI 任务助手

**技术栈：** React、TypeScript、TanStack Query、Python、FastAPI、LangGraph、LangChain、DeepSeek、MySQL、SQLAlchemy、Alembic、Docker Compose、GitHub Actions

**源码：** [GitHub · yaowcui-ai/homemind](https://github.com/yaowcui-ai/homemind)

**项目介绍：** 面向多设备联动与舒适度、能耗取舍场景，开发从自然语言需求、澄清确认到执行核验的智能家居应用；支持多账号独立家庭、可配置设备、任务历史和单／多 Agent 实验，设备与环境使用确定性仿真。

- **全栈交互与数据隔离：** 基于 React／TypeScript 和 FastAPI 实现设备控制、任务详情、澄清确认与刷新恢复；使用 TanStack Query 管理服务端状态，MySQL 异步持久化家庭、偏好、任务和动作记录，结合 Cookie 会话、CSRF 与家庭归属校验实现账号隔离。
- **Agent 编排与约束：** 基于 LangGraph 实现“结构化目标 → 隔离预测 → 舒适／节能专家并行 → 协调选择”，最多比较 4 个候选，校验目标、保留项与候选一致性；Agent 只读事实，统一执行器写入设备，并提供使用相同预测资料的单 Agent 对照。
- **可靠执行：** 将模型推理置于数据库事务外，在短事务中重验版本并落库；以幂等键、请求摘要和版本前置条件处理重复提交及过期方案，支持未知响应后查询持久记录、原键重试；分别核验动作读回与目标时刻温度，避免将设置成功误报为目标达成。
- **资源与质量保障：** 设置模型共享原子调用预算（6 次／轮、12 次／任务）、20 秒单次和 65 秒整轮限制，约束预测规模与线程占用；通过真实 MySQL、API 进程重启、浏览器端到端检查及 GitHub Actions 验证持久化与核心操作流程。
- **评测与定向调优：** 建立 44 例开发案例库，以有限字段诊断定位约束漂移和澄清缺字段，修订阶段契约提示并同条件复测；另预冻结 12 个新案例及 3 例重复方案，完成 36 次单／多 Agent 运行、98 次真实模型请求，保留失败、未知用量和评分依据；新集未证实多 Agent 优势，维持实验入口。
