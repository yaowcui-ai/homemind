# HomeMind｜智能家居 AI 任务助手

**技术栈：** React、TypeScript、TanStack Query、Python、FastAPI、LangGraph、LangChain、DeepSeek、MySQL、SQLAlchemy、Alembic、Docker Compose

**项目介绍：** 面向多设备联动与舒适度、能耗取舍场景，开发从自然语言需求、澄清确认到执行核验的智能家居应用；支持多账号独立家庭、可配置设备、任务历史和单／多 Agent 实验，设备与环境使用确定性仿真。

- **全栈交互与数据隔离：** 基于 React／TypeScript 和 FastAPI 实现设备控制、任务详情、澄清确认与刷新恢复；使用 TanStack Query 管理服务端状态，MySQL 异步持久化家庭、偏好、任务和动作记录，结合 Cookie 会话、CSRF 与家庭归属校验实现账号隔离。
- **多 Agent 编排：** 基于 LangGraph 实现“目标提取 → 隔离预测 → 舒适／节能专家并行 → 协调选择”，通过结构化目标与候选方案绑定约束模型输出；Agent 仅访问只读事实，设备写入由统一执行器完成，保留同预测资料的增强单 Agent 对照入口。
- **可靠执行与结果核验：** 为创建、补答、确认和仿真推进设计幂等键、请求摘要及版本前置校验，支持未知响应后的持久记录查询与原键重试；将动作读回与目标时刻温度证据分开验证，阻断过期方案、保留项冲突及零动作误报成功。
- **预测与调用资源控制：** 基于精确状态克隆比较最多 4 个温控候选，设置家庭规模、计算步数及工作线程上限，处理取消与超时；模型调用采用每轮 6 次／任务 12 次共享原子预算、单次 20 秒／整轮 65 秒限制，保留阶段调用量和未知 Token 状态。
- **真实评测与定向调优：** 建立 44 例开发案例库，完成 6 对同初态单／多 Agent 真实模型对照，分别评价硬目标、偏好一致性、异常处置与调用成本；通过不保留被拒内容的字段级诊断，定位保留列表漂移和澄清缺字段，补充阶段契约提示并完成同条件定向复测。
