# HomeMind 智能家居多 Agent 助手｜AI 全栈开发

**技术栈：** React · TypeScript · Python · FastAPI · LangGraph · LangChain · MySQL · Docker Compose

**源码：** [GitHub · yaowcui-ai/homemind](https://github.com/yaowcui-ai/homemind)

面向温控联动与舒适／能耗取舍，构建自然语言规划、澄清确认、执行与目标核验闭环；接入 DeepSeek 官方 API，设备与环境采用确定性仿真。

- **多 Agent 编排：** 基于 LangGraph 编排目标提取、舒适／节能专家并行分析与协调选择，提供共享预测资料的单 Agent 对照；通过结构化契约约束输出，Agent 只读事实，由统一执行器校验保留项、保护范围与候选一致性后执行。
- **预测与目标核验：** 从精确状态副本推演最多 4 个温控候选，比较截止温度、首次达标时间与范围能耗；React 展示候选、角色分歧及确认流程，分别核验设备动作读回与目标时刻温度，避免将设置成功误报为目标达成。
- **可靠执行与恢复：** 将模型推理移出数据库事务，执行前重验家庭状态版本；结合幂等提交和持久化任务、动作记录，处理过期方案、重复请求及提交后丢响应，支持刷新后查询原结果，避免重复控制设备。
- **定向评测与调优：** 构建92例分层案例库，覆盖目标理解、偏好排序、保护约束及多轮澄清；通过房间实体索引、精确候选对比、专家证据白名单及用户约束记忆修复真实失败。24个固定开发场景中，多Agent通过数由21/24提升至23/24（87.5%→95.8%）；另12个冻结新场景，单／多Agent均通过。
- **全栈交付：** 打通React任务交互、FastAPI接口与MySQL持久化，使用Docker Compose一键启动Nginx、API及数据库，通过数据库迁移、就绪检查和GitHub Actions自动验证支撑部署与迭代。
