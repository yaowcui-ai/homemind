# M2 可配置家庭与设备仿真验证记录

日期：2026-10-26，Windows PowerShell。本阶段从 M1 提交 `5a86177` 开始，分支 `codex/m2-simulation`。用户“ok，开始下一步。”授权 M2；完成后停在 M3 之前。

## 已交付

- 后端每个应用实例独立的 `demo-home`：客厅/卧室各六实体，共六可控、六只读。ID 与名称分离，复制不共享可变状态。
- 房间和实体的增加、编辑、停用、改名、迁移、归档；非空房间删除冲突；主温度/占用显式绑定、失效后清空，公开未知保留 null。
- 能力与配置按类型严格校验；传感器控制被拒绝。环境事件单独注入温度、占用、窗户或观测质量；错误输入不留下半更新。
- 逐分钟十进制热模型、灯/空调/窗帘能耗，可推进 1—1440 分钟；配置/状态版本、独立快照、锁内串行写入。
- 离线、执行前失败、执行后响应丢失、无效果、延迟五种故障；每实体最多一个待执行动作，配置及故障变化会取消它。
- reset 保留用户清单、ID、名字、归属、主绑定、启用与保存配置，生成新 world_id；时间、能耗、故障和待执行动作清空，归档实体不恢复。
- React 真实控制台、配置表单、故障抽屉、时间推进、状态刷新、重置确认、最近变化、手机适配；运行状态与待提交目标分开，提交后独立 GET 读回。
- version=0.2.0、stage=M2；未鉴权演示接口不在 production 环境挂载。

## 实际流转与复现

启动命令见项目 [README](../../README.md)，后端 8100、前端 5174。浏览器测试独立启动临时服务，禁止复用用户服务；代理绕过只加到测试进程，未修改系统代理。后端控制返回 ControlResult，网页再 GET 独立快照，不把“请求已提交”当作实际状态。

模型公式、单位、事件语义和全部 API 见 [实施设计](../superpowers/specs/2026-10-26-m2-simulation-design.md)，到期分钟顺序、已归档能耗和内部物理/公开观测差别见 [实现约定](../../backend/src/homemind/simulation/README.md)。多次推进的确定性与 20 分钟等价两次 10 分钟由后端用例验证。

## 边界

本阶段只有未鉴权的本机单家庭内存演示，重启恢复默认模板，不支持多 worker 保存或跨进程恢复。无数据库、注册、账号隔离、Agent、SSE、真实模型或硬件。内部关闭窗户/无人假设不会伪装为公开有效读数。温度和能耗是功能验证假设，不能证明真实舒适度或节电效果。最近 50 条事件不等同于持久历史；本轮没有触发远端 CI、发布代码或网站。
