## 启动

Docker Desktop运行后，在项目根目录执行：

```powershell
docker compose --env-file .local/mysql.env up -d --build --wait
```

打开 <http://127.0.0.1:18080/>。alice原家庭保留，重置后的凭据仍仅在本机.local/alice-login.txt，本轮没有再次改密码。迁移容器Exited(0)正常。停止用同一配置的stop，不删除数据卷。
